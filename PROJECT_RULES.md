# Ūrēi Works Index — shared production rules

This repository is the canonical source for the Ūrēi mothership site. Any AI or person editing it must follow these rules.

1. Treat the repository version as the source of truth. Do not leave a newer canonical version only inside a chat, artifact, canvas, or ZIP.
2. Preserve existing public links and behavior unless a requested change explicitly replaces them.
3. New works enter as `LINK ONLY` or `SOURCE HUNTING`. Do not claim that source is archived until the complete project is actually stored and verified.
4. A user note about what they liked is a priority hint, never the boundary of analysis. Independently inspect the whole reference first.
5. Keep verified facts, technical inference, and unverified assumptions clearly separate.
6. Before adopting a technology, compare current alternatives for visual quality, runtime weight, device support, privacy, maintenance, and license.
7. For important visual techniques, make a small comparison prototype before integrating them into a production app.
8. Update the works index when a public URL, source repository, or release status changes.
9. Maintain responsive behavior for iPhone and desktop, keyboard accessibility, reduced-motion support, and readable type.
10. At the end of a change, report what changed, what was tested, what remains unverified, and whether it was published.
